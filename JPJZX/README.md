# 📦 集装箱竞拍模拟器 - 塔科夫搜刮版

## 🎮 项目简介
一款以集装箱竞拍为主题的模拟游戏，采用类似《逃离塔科夫》的 81 格网格搜刮系统，提供爽快刺激的游戏体验。

## ✨ 核心特性

### 🎯 游戏系统
- **8 张地图**：从废弃港口到虚空裂缝，难度递增
- **8 回合竞拍**：每回合竞拍一个集装箱
- **AI 对手系统**：4 个具有不同性格的 AI 对手
  - 影刃（激进型）
  - 夜枭（谨慎型）
  - 猎鹰（平衡型）
  - 毒牙（随机型）
- **声望系统**：影响游戏评价
- **贷款系统**：资金不足时可贷款
- **随机事件**：幸运轮盘、神秘包裹、投资机会等

### 🎒 81 格网格系统
- **背包系统**：9×9=81 格网格背包
- **仓库系统**：9×9=81 格网格仓库
- **物品尺寸系统**：
  - 1×1, 1×2, 2×1, 2×2, 2×3, 3×2, 3×3 等多种尺寸
  - 智能放置算法，自动寻找可用空间
- **搜刮动画**：
  - 点击迷雾格子触发
  - 渐进式揭示动画
  - 粒子特效
  - 品质颜色显示

### 🎁 物品系统
- **385 种物品**：超过 300 种物品的要求
- **5 种品质**：
  - 🟢 绿色（80 个）- 基础物品
  - 🔵 蓝色（70 个）- 精良物品
  - 🟣 紫色（60 个）- 史诗物品
  - 🟡 金色（50 个）- 传说物品
  - 🔴 红色（50 个）- 神话物品
- **多种类别**：
  - 武器、护甲、医疗、电子
  - 贵重物品、材料、容器、特殊物品

### 🎨 视觉风格
- **赛博朋克 + 军事迷彩**：霓虹配色
- **动态效果**：
  - 集装箱浮动动画
  - 粒子特效
  - 品质光效
  - 红色物品脉动动画
- **响应式设计**：适配不同屏幕尺寸

### 🎮 游戏机制
- **竞拍系统**：
  - 起始价 1000
  - 每次加价 500
  - 特殊行动：侦察、压价、干扰
- **战利品生成**：
  - 每箱 6-11 个物品
  - 根据地图掉落率调整品质概率
  - 高难度地图高品率更高
- **自动收纳**：
  - 优先放入背包
  - 背包满时自动放入仓库
- **回合系统**：
  - 8 回合后结算
  - S/A/B/C/D 评级系统

### 🏪 子系统
- **仓库管理**：物品分类、排序、转移、出售
- **黑市商店**：购买物品、每日特惠、品质筛选
- **合成实验室**：物品合成、品质升级、成功率系统
- **搜刮系统**：迷雾揭示、自动扫描、物品收集

## 🚀 游戏操作
1. **选择地图**：点击地图卡片选择要竞拍的地图
2. **开始竞拍**：点击"开始竞拍"按钮
3. **出价/放弃**：轮到你时选择出价或放弃
4. **特殊行动**：使用侦察、压价、干扰等技能
5. **搜刮物品**：竞拍成功后点击迷雾格子搜刮
6. **管理背包**：查看背包和仓库，整理物品
7. **合成物品**：在合成实验室升级物品品质
8. **商店交易**：在黑市商店买卖物品
9. **保存进度**：随时保存游戏进度

## 🎯 爽点设计
- **高爆率**：调整概率，增加高品率
- **多物品**：每箱 6-11 个物品
- **即时反馈**：
  - 出价成功提示
  - 获得物品提示
  - 稀有物品特殊提示
- **渐进揭示**：逐个揭示物品的惊喜感
- **粒子特效**：每个物品揭示时的视觉反馈
- **自动收纳**：无需手动整理，自动放入可用空间

## 🏆 结局评级
- **S 级**：总资产 > 50000
- **A 级**：总资产 > 30000
- **B 级**：总资产 > 20000
- **C 级**：总资产 > 10000
- **D 级**：总资产 <= 10000

## 💾 存档系统
- 使用 localStorage 保存
- 保存内容：
  - 资金、声望、回合数
  - 背包和仓库状态
  - 物品统计信息
- 自动保存功能
- 跨页面数据同步

## 🏗️ 架构设计
- **状态管理**：统一的 GameState 管理器
- **模块系统**：ModuleManager 协调各子系统
- **事件驱动**：状态变更自动通知所有模块
- **数据共享**：所有页面共享同一份游戏数据

## 🌐 部署说明
可直接部署到 GitHub Pages：
1. 将 JPJZX 文件夹推送到 GitHub 仓库
2. 在仓库设置中启用 GitHub Pages
3. 选择主分支作为源
4. 访问生成的 URL 即可游戏

## 📊 技术栈
- **纯 HTML/CSS/JS**：无外部依赖
- **模块化设计**：分离的 JS 模块
- **CSS Grid**：81 格网格布局
- **CSS Animations**：流畅动画效果
- **LocalStorage**：本地存档
- **事件系统**：模块间通信

## 🔧 扩展性
- **添加新物品**：在 items.js 的 ITEMS_DATABASE 中添加
- **添加新地图**：在 game.js 的 MAPS 数组中添加
- **添加新模块**：使用 ModuleManager.register() 注册
- **添加新事件**：在 RANDOM_EVENTS 数组中添加
- **自定义样式**：修改 style.css

## 🎮 游戏目标
在 8 回合内通过竞拍和搜刮积累最多财富，获得最高评级！
